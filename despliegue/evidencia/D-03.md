# D-03 — Verificación desde la URL pública

Fecha: 2026-11-08  
URL: `https://libreria.enzogiaquinta.me`  
Objetivo: demostrar que el backend desplegado responde desde afuera y que una
venta real funciona.

## Comandos y salidas

```text
GET /health/ready   -> 200 {"status":"ok"}
GET /health/live    -> 200 {"status":"ok"}
GET /libros/        -> 200 catálogo del seed
```

Venta real:

```json
{"cliente_id":1,"renglones":[{"libro_id":4,"cantidad":1}]}
```

```text
POST /ventas/ -> 201
id: 4
total: "27000.00"
libro_id: 4
cantidad: 1
```

Stock antes/después de `libro_id=4` (Respiración artificial):

```text
antes:  3
después: 2
```

Prueba de stock insuficiente:

```json
{"cliente_id":1,"renglones":[{"libro_id":5,"cantidad":2}]}
```

```text
POST /ventas/ -> 409
{"detail":"Stock insuficiente para 'Bestiario'"}
```

## Lectura

La API está pública y healthy, el catálogo del seed se lee, la venta responde
201 con precios y total del servidor, el stock baja en la misma transacción y el
409 por stock insuficiente no escribe la venta.
