## Hallazgos por severidad

1. **[WARN] C-07.11 no es auto-concluyente en REST Client.** `@vence_en_corto = 2030-01-01T00:00:00Z` es una fecha fija: tal cual está, el bloque devuelve 200 (rol vigente), no el 403 del caso. El propio archivo lo advierte y pide editar la variable a mano; la evidencia concluyente (200 antes / 403 después) está en `manual-c07-vencimiento.txt`. No es defecto del servidor, es limitación de formato declarada con honestidad.
   **Fix propuesto (no urgente):** dejar en el encabezado del bloque C-07.11 los pasos exactos para regenerar el 403 (mismo procedimiento que `manual-c07-vencimiento.txt`), ya documentados en `EVIDENCIA.md` §5.
2. **[WARN] La pasada manual con httpyac corrió sobre copias temporales `_compat/`**, no byte-a-byte sobre los entregables (httpyac no resuelve `response.headers.Set-Cookie` de REST Client; la copia exporta la cookie en un script). `EVIDENCIA.md` §9 lo declara explícitamente y afirma que las peticiones no cambiaron. Los `.http` entregados quedan verificados estáticamente (estructura, `# Esperado:`, `# @name`/`# @no-cookie-jar`, cookie explícita) + corrida equivalente `httpx` por caso.
   **Fix propuesto:** durante la revisión del usuario en VS Code REST Client, regenerar una captura por archivo para cerrar la brecha GUI; C-19 ya está previsto para consolidar evidencia.
3. **[WARN] Defecto conocido `dd4a0e5e9cf7`** (timestamps congelados por `server_default='now()'`). Referenciado como defecto conocido en auditorías anteriores (c-17); C-18 no lo introduce ni lo oculta. Registrar como deuda abierta, no como regresión.
4. **[INFO] Desvíos documentados de C-16** (`EVIDENCIA.md` §8): el mensaje «La página 4 no existe: hay N» depende de `size` (caso corregido a `size=2&page=4` → «hay 3», que es el ejemplo de la consigna) y `size=500` se rechaza en la capa HTTP (`less_than_equal`). Ambos son comportamiento correcto del servidor; los `# Esperado:` coinciden con lo observado.
5. **[INFO] C-14: exit code ≠ criterio.** `psql -f` sin `ON_ERROR_STOP` termina con código 1 por los dos ERROR **esperados**; el criterio (y lo verificado) es el texto de ambos errores + `count(*) = 7`. Correctamente declarado en `EVIDENCIA.md` §9.
